# Spec Archive

Archived feature specs from the former **speckit** workflow (`.specify/`, `specs/`), which the project has replaced with **OpenSpec** (`openspec/`).

These documents describe shipped milestones and are kept as a **historical record**. They are **not** the live source of truth — do not edit them:

- **Live workflow**: OpenSpec under `openspec/`. Active changes live in `openspec/changes/*`; archived changes (the authoritative project spec) live in `openspec/specs/*`.
- **Workflow commands**: `/opsx-propose`, `/opsx-apply`, `/opsx-archive` (see `.opencode/commands/opsx-*.md`).
- **Project principles**: `docs/constitution.md` (superseded in day-to-day use by `AGENTS.md`, which remains authoritative).
